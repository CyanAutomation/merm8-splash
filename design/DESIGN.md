# merm8 design system

merm8 is a focused Mermaid diagram checker. The interface uses a compact charcoal workspace, clear boundaries, reusable controls, and calm status colors so people can edit, preview, and check diagrams without distraction.

The frontend guidance in [frontend-design-guidance.md](./frontend-design-guidance.md) is the single source of truth for palette, components, responsive behavior, accessibility, and product language. Keep this overview aligned with that guide when the interface changes.
